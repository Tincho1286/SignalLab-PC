# Plan de ejecución de Fase 04

| Paquete | Entrega y dependencia |
| --- | --- |
| WP-00 | Línea base verificada, requisitos, clasificación fija de componentes críticos y criterios de salida. |
| WP-01 | Contrato LTI de trayectorias, impulso y frecuencia, PDP, momentos, ISI y normalización. Evaluación del error de retardos fraccionarios. |
| WP-02 | Fading Rayleigh/Rician plano y selectivo. Potencia explícita por camino, fase LOS, K lineal/dB y pruebas de distribución. |
| WP-03 | Rotación Doppler determinista y fading correlacionado. Verificar resolución temporal, autocorrelación, espectro y coherencia. |
| WP-04 | CFO, fase, desplazamiento temporal, SFO validado, ruido de fase, interferencia y desequilibrio I/Q. Comparar contra señales de referencia. |
| WP-05 | Pérdidas de propagación básicas y composición con orden, reloj, semillas, registros, potencia y advertencias. Reutilizar servicios y persistencia del Core. |
| WP-06 | Modelos en el enlace integrado de Fase 03 y casos ideales/estocásticos/combinados. Conservar los perfiles históricos y las reglas de alineación. |
| WP-07 | Entradas, gráficos, informe y ayuda de escritorio, API y CLI sobre los mismos servicios. Contrastar salidas y ejecución sin Qt. |
| WP-08 | Barridos y réplicas de canal con semillas reproducibles, CSV y recuperación. Validar ida y vuelta de configuraciones, resultados y señales intermedias. |
| WP-09 | Referencias independientes, pruebas preventivas, seguridad, recursos, cancelación, cobertura y escritorios. |
| WP-10 | Matriz Windows/Linux sobre un mismo SHA limpio, artefactos 2.2.0 Preview y dictámenes técnicos separados. |

Las verticales incluyen sus pruebas y documentación durante la implementación. El lector histórico, el enlace QPSK/RRC/AWGN y los límites operativos aprobados sirven de control a lo largo de todos los paquetes. Los ensayos completos de distribución quedan para el candidato final.
