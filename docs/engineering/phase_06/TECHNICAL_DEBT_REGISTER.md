# Límites y seguimiento

| Tema | Límite y criterio de ampliación |
| --- | --- |
| Referencia RF | Referencias reales positivas y ondas de potencia. Una extensión a impedancias complejas requiere casos independientes de potencia y comparaciones de convenios. |
| Adaptación | L, cuarto de onda y stub. Pi y T requieren fijar una impedancia intermedia o un criterio de ancho de banda y Q que permita contrastar sus soluciones. |
| Dispositivos | Núcleo cúbico hasta 1 dB de compresión. La saturación requiere una ley física adicional y datos de validación. |
| Filtros como dos puertos | H(s) se mantiene como función de transferencia escalar. Para construir un S completo hacen falta relaciones de onda, puertos y terminaciones adicionales. |
| Touchstone | Versiones 1.0 y 2.0 single ended, S/Z/Y. Quedan fuera mezcla modal, parámetros híbridos, ruido y 2.1. |
| Resultados nativos prolongados | Cancelación cooperativa en límites de bloque y antes de persistir. Un endurecimiento de aislamiento requiere medir el coste de trasladar datos entre procesos. |

Las restricciones de almacenamiento, MAT confiable y distribución se siguen en el registro acumulado del proyecto. [Deuda acumulada](../TECHNICAL_DEBT.md)
