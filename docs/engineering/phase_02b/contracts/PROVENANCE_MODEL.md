# Modelo de procedencia

La representación persistida identifica la operación y la versión de su contrato. Los modelos específicos describen parámetros efectivos, unidades, origen y reloj. `Project.parents` guarda IDs de entrada y dependencias para que una fusión pueda remapearlos. `Signal.metadata` contiene el contrato científico. Los tiempos y la memoria observada se guardan en informes de ejecución. El backend de los motores vigentes se documenta por operación. No se añaden huellas de cada arreglo ni semillas a operaciones deterministas.
