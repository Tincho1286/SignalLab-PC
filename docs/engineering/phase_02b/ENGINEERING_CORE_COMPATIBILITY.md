# Compatibilidad de Engineering Core

La API previa de DFT preserva sus nombres y las convenciones del motor. Se conserva la referencia de fase explícita del piloto. Los proyectos y sesiones conservan sus esquemas. Los resultados de DSP agregan metadata de procedencia y usan relaciones que Project ya remapea al fusionar. El backend opcional de una señal se identifica por su propia cabecera.

La ruta `python -m signallab_pc` conserva el escritorio. Los comandos headless se seleccionan antes de la importación de Qt. Los ejemplos también pueden usarse en una celda de Jupyter instalada por el usuario.
