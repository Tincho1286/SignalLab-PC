# Agregar una operación

1. Definir dominio, unidades, normalización y condiciones límite. Identificar el motor existente y sus puntos cooperativos.
2. Crear una solicitud tipada con parámetros específicos. Calcular recursos antes de la primera asignación grande y ejecutar con `ExecutionContext`.
3. Devolver el modelo de dominio y registrar parámetros efectivos con `scientific_metadata`. Versionar campos que cambien de significado. Guardar referencias de entradas en Project.
4. Adaptar Qt y CLI. Para un flujo, definir explícitamente dependencias, reloj y política de publicación.
5. Probar un vector analítico, cancelación o error, y el uso por interfaces. Incluir compatibilidad histórica si el modelo estaba en sesiones.
6. Registrar decisión, pruebas, resultado y límites. Extender el registro de familias matemáticas cuando corresponda.
