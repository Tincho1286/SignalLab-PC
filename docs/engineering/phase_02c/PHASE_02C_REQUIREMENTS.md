# Requisitos

- **C00–C02**. Reconstruir riesgos, dependencias y convenciones matemáticas con evidencia ligada a un SHA.
- **C03–C05**. Verificar la procedencia contra los datos efectivos, establecer límites de trabajo y preservar la integridad de sesiones y señales.
- **C06–C09**. Validar cobertura significativa, rendimiento, escritorio y entrega descartable.
- **C10–C11**. Revisar arquitectura y emitir dictámenes separados para Core, Fase 03 y distribución.

Se preservan las interfaces públicas y los formatos predeterminados. La entrega se limita a la fase autorizada. [Matriz de trazabilidad](TRACEABILITY_MATRIX.md)
