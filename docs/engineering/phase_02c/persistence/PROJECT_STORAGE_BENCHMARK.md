# Banco de persistencia de proyecto

Se mide preparación de la señal, publicación de una DFT con padres, guardado, reapertura y tamaños de archivo como etapas separadas. El banco 02C conserva repeticiones y pico residente. Para intercambiar una sola señal compara lectura y escritura SLBIN en el mismo perfil de proceso. Las mediciones previas corresponden a tamaños y versiones identificados en [evidencia de Fase 02B](../../phase_02b/benchmarks/).
