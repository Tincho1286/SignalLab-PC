# Plan de trabajo

| Paquete | Resultado verificable |
| --- | --- |
| 00 · Retrospectiva | Línea base contrastada y deuda con criterios previos de cierre. |
| 01 · Seguridad | Revisión de versiones, SBOM, entradas y riesgos aplicables. |
| 02 · Matemática | Oráculos independientes y resolución de defectos críticos conocidos. |
| 03 · Contratos | Correspondencia comprobable entre datos de cálculo, resultado y padres. |
| 04 · Recursos | Medidas, límites operativos y pruebas de contención y cancelación. |
| 05 · Persistencia | Especificación, integridad, comparativas y compatibilidad histórica. |
| 06 · Pruebas | Cobertura con comprobaciones significativas y revisión de faltantes. |
| 07 · Rendimiento | Benchmarks reproducibles y umbrales adecuados al entorno. |
| 08 · Escritorio | Pruebas funcionales y matriz visual con distinción de DPI y backend. |
| 09 · Distribución | Instalación y actualización descartables con evidencias por plataforma. |
| 10 · Arquitectura | Análisis de dependencias y preparación técnica evaluativa. |
| 11 · Validación final | Matriz sobre un SHA limpio y tres dictámenes independientes. |

Se trabaja sobre `develop`. Los controles que dependan de terceros conservan su estado y criterio de revisión mientras avanzan los demás paquetes.
