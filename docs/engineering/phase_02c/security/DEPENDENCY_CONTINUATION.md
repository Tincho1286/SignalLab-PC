## Corrección de empaquetado para E-01

El índice oficial de compilaciones de Qt publica ruedas de Essentials y shiboken6 6.12.1 para Windows x64 y Linux x86-64. El lock selecciona la plataforma y fija cada URL por ID de compilación y SHA-256. Se comprobaron los metadatos y las huellas `RECORD` de las cuatro ruedas. En las dos plataformas se identificó QtCore 6.12.1 en el binario. En Windows se cargó el runtime con PySide6, shiboken6 y QtSvg de ese lote y pasaron las dos regresiones de fondos. Las ruedas provienen del directorio de compilaciones de Qt mientras las de PyPI se publican. [Compilación oficial fijada](https://download.qt.io/snapshots/ci/pyside/6.12.1/592558ac336742a93200f55e15c09e8e17eb13a5/pyside6/) · [Aviso corregido](https://www.qt.io/blog/security-advisory-cve-2026-105924)

SignalLab admite fondos PNG, JPEG, BMP y WebP. El empaquetado compila el fuente de Pillow 13.0.0 con `jpeg2000=disable` y exige JPEG, zlib, TIFF y WebP. En Windows usa MSVC, CMake, Ninja y NASM con las recetas de Pillow. En Linux usa las bibliotecas de desarrollo de Ubuntu. El diagnóstico del ejecutable congelado comprueba el estado del códec y genera y vuelve a leer figuras PNG, JPEG, TIFF y WebP. El SBOM comprueba la versión compilada de Qt y que el binario no arrastre una biblioteca OpenJPEG o un plugin Qt JPEG 2000. [Compilación de Pillow](https://pillow.readthedocs.io/en/stable/installation/building-from-source.html) · [Seguimiento de OpenJPEG](https://github.com/uclouvain/openjpeg/issues/1652)

La revisión deja E-01 pendiente hasta comprobar los dos portables del mismo SHA. La matriz de `a80508c` conserva su inventario original.
