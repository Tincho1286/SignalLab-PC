# Revisión de componentes de la continuidad 02C

Fecha de consulta 25/11/2026. La consulta de `https://pypi.org/pypi/{paquete}/json` comparó la versión fijada con las versiones estables posteriores que publican alguna rueda no retirada. La consulta por versión específica devolvió HTTP 404 para PySide6-Essentials y shiboken6 6.12.1, h5py 3.17.0 y Pillow 13.0.1.

Qt se distribuye dentro del portable. | Mantener el lock reproducible. Esperar ruedas compatibles para ambas plataformas o una compilación corregida y trazable. Confirmar la corrección específica del aviso y reconstruir y verificar ambos portables. |
| OpenJPEG 2.5.4 · E-01 | Sigue marcado como última versión por el proveedor. Pillow 13.0.0 sigue siendo la última rueda estable. El inventario Linux incluye OpenJPEG. | HDF5 2.0.0 · E-02 | El proveedor aún no lista versión corregida para GHSA-r7g4-hv2f-5c66. h5py 3.16.0 sigue siendo la última rueda estable. La trayectoria MAT recorre objetos y busca por nombre el atributo MATLAB_class. Se excluyen los enlaces externos, los datos externos o virtuales, los tipos de referencia y los filtros no autorizados. Mantener como alcance archivos seleccionados localmente y desaconsejar su uso como ingreso automático de archivos externos. Exigir una rueda con corrección confirmada y repetir la suite de importación y empaquetado. |
| SciPy 1.18.0 y cryptography 50.0.2 | La consulta encontró SciPy 1.18.1. Sus notas no identifican una corrección del lector MAT ni un aviso aplicable a esta auditoría. cryptography permanece en la última rueda estable encontrada. | Se conservó el lock del candidato. El MAT clásico usa el mismo proceso con cuota, límite de formato y plazo. La actualización general de SciPy queda fuera de esta revisión de avisos. |

El subproceso MAT limita el impacto de un cierre del lector o un consumo excesivo. Corre con los permisos de la cuenta y sus controles de formato se aplican después de iniciar el parser nativo. El proceso separado no constituye un aislamiento de privilegios. E-01 y E-02 mantienen decisión individual abierta.

Se repitió la consulta OSV por lotes con las 28 entradas exactas registradas, incluida coverage.py. La respuesta volvió a indicar cero avisos indexados para esos paquetes y versiones. El inventario de código nativo se verifica por separado en la matriz. [Consulta de referencia](osv-lock.json)
