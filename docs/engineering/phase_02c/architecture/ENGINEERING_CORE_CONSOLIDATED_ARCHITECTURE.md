# Engineering Core consolidado

El modelo contiene muestras, coordenadas, unidades y metadatos científicos. Los adaptadores validan cada solicitud y usan los motores de dominio. El contexto común propaga plazos, progreso y presupuesto. Las API pública experimental y CLI producen cálculos que se pueden guardar como resultados tipados y verificar al reabrir.

El acceso directo de los paneles históricos y la revisión de aplicaciones futuras se mantienen en la capa de presentación. Las pruebas controlan la ruta compartida elegida para el piloto.
