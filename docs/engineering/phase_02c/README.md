Ambas plataformas superaron 85 % de líneas y 75 % de ramas. La recuperación asíncrona, la hoja CAS persistente y la campaña de 48 corridas forman parte de los perfiles verificados. El mantenedor aceptó las pruebas manuales de escritorio en las dos plataformas. La preparación para Fase 03 y la distribución conservan sus propios dictámenes.
