# Criterios de salida

Mismo SHA limpio para la matriz Windows x64 y Linux x86-64. Cada prueba se enlaza con el hallazgo o requisito que cubre. El cierre exige cero P0 abiertos y cero P1 abiertos sin resolución o aprobación expresa. Todo defecto matemático crítico, pérdida o corrupción conocida e inconsistencia crítica de procedencia debe resolverse.

Cobertura de líneas de 85 % en toda la aplicación y de 90 % en Muestreo, Fourier, ejecución, adaptadores DSP, flujo, almacenamiento científico y sesión de CLI. Objetivos de ramas de 75 % global y 85 % en rutas críticas del Core. Los incumplimientos requieren evaluación individual y aceptación explícita.

Los dictámenes de Engineering Core, Fase 03 y distribución pública se emiten por separado. Qt, DPI de sistema, canal público, CAS y concurrencia se revisan con alcance y evidencia propios.
