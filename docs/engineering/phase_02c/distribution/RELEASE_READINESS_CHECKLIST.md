# Requisitos de distribución

- Comprobar binarios, instaladores, diagnósticos y SBOM de ambos sistemas sobre el mismo SHA.
- Resolver la excepción de Qt o documentar el alcance y obtener aceptación si corresponde.
- Confirmar autoría del instalador Windows con una firma autorizada cuando esté disponible.
- Verificar el salto desde 2.0.0 a una versión superior empaquetada y el comportamiento del canal de publicación bajo autorización.
- Completar el protocolo de escritorio real para el alcance soportado.
- Autorizar expresamente cualquier publicación, promoción o tag.
