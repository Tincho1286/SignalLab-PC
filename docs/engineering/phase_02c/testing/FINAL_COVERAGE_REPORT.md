# Cobertura de la Fase 02C

La cobertura definitiva se calcula con `tools/check_engineering_baseline.py` sobre el candidato limpio. Debe incluir líneas y ramas para ejecución, DFT, adaptadores, flujo, almacenamiento y sesión CLI además de los módulos matemáticos. El informe de la puerta de calidad comparará los valores efectivos de ambos sistemas con los objetivos. Una brecha requiere aprobación individual antes del cierre.
