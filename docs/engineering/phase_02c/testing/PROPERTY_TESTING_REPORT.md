# Pruebas de propiedades

El oráculo de energía usa Parseval y sumas discretas. Las referencias de PSD prueban conservación de potencia, plegado unilateral y escalas extremas. Las referencias de filtrado comprueban retardo, ganancia, transitorio y polos cercanos. Se incluyen semillas fijas en ruido y casos sintéticos acotados para formatos. Todavía no se ejecutó mutation testing general ni se introdujo un framework adicional.
