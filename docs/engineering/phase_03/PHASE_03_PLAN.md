# Plan de Fase 03

| Paquete | Entrega verificable |
| --- | --- |
| WP-00 | Consolidar 02C sobre un SHA, auditar arquitectura y dependencias y fijar las condiciones científicas de aceptación. |
| WP-01 | Representar bits, símbolos, constelaciones, señales I/Q y sus relojes, configuraciones y procedencia. |
| WP-02 | Implementar PSK y QAM cuadrada, mapeo natural y Gray, energía, rotación y decisión dura. |
| WP-03 | Generar pulsos rectangular, RC y RRC, aplicar sobremuestreo y reutilizar el filtrado FIR. |
| WP-04 | Ejecutar AWGN real y complejo, recuperación de símbolos y sincronización de referencia y básica. |
| WP-05 | Medir BER, SER y EVM y contrastar curvas teóricas y Monte Carlo con oráculos independientes. |
| WP-06 | Integrar el demostrador QPSK en Workbench, Python y CLI con las mismas operaciones y visualizaciones científicas. |
| WP-07 | Guardar y comparar experimentos y barridos reproducibles, con cancelación, recuperación y exportación. |
| WP-08 | Verificar cobertura, compatibilidad, empaquetado, seguridad, recursos, rendimiento y los tres dictámenes finales. |
