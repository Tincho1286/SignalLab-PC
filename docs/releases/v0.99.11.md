# SignalLab PC 0.99.11 · Preliminar

Esta preliminar histórica reúne las distintas formas de diseñar un filtro en un documento común, conservando parámetros propios para cada definición.

## Diseño y acciones del resultado

El acceso agrupa especificaciones FIR/IIR, cortes, h[n], raíces, segundo orden y RC. Dominio y estructura aparecen cuando aportan una elección útil, y cada formulario conserva sus valores al cambiar de método.

El filtro calculado reúne análisis, reutilización y exportación, incluyendo JSON de filtro y CSV de respuesta. Los formularios se despejan y la ayuda utiliza colores para relacionar las entradas con el diseño. La línea estable posterior comienza en 1.0.0.
