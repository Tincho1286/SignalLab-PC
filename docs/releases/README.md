## Lectura del historial

Las notas describen los cambios de la versión indicada. Las guías generales se actualizan para la estable actual y pueden explicar funciones posteriores a una entrega histórica. Cada página enlaza únicamente formatos que existen entre sus adjuntos.

Las notas del repositorio y el cuerpo de las Releases pueden recibir correcciones editoriales. Los documentos adjuntos, los binarios, los archivos de fuentes y sus checksums conservan la copia original de su publicación. La revisión del texto no reemplaza esos archivos ni modifica las etiquetas o el estado de las entregas.

Las notas anteriores a la promoción de [1.6.15](v1.6.15-preview.md) y [1.6.17](v1.6.17-preview.md) se conservan como antecedentes de sus estables, sin presentarlas como publicaciones adicionales.
