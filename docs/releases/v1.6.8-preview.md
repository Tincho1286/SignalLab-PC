# SignalLab PC 1.6.8 · Preliminar

Esta entrega mejora las transformadas numéricas, el análisis espectral y la reutilización de señales.

- Z inversa por contorno analiza los polos después de las cancelaciones exactas y admite el último índice distinguible de una rejilla impar.
- La energía por banda de una DFT completa se calcula sumando sus bins. La transformada continua conserva el mismo eje durante el cálculo y al mostrar el resultado.
- Las inversas numéricas distinguen los pesos de líneas espectrales de las muestras ordinarias. La PSD escala cada tramo antes de restar su media.
- Hilbert y STFT activan el dominio de la entrada recibida. El producto punto a punto valida que ambas señales compartan el tipo de eje.
- La normalización de ganancia y la varianza muestral evitan desbordamientos intermedios.
- El diagnóstico integrado abre las herramientas mediante la navegación actual y comprueba la ventana de figuras.

Disponible como portable para Windows x64 y Linux x86_64.
