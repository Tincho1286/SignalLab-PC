# SignalLab PC 1.9.1 · Preliminar

## Sintaxis de las fórmulas

En **Ayuda → Funciones de las fórmulas**, cada ficha presenta la sintaxis y explica los argumentos en el orden en que se escriben. Las explicaciones indican cuándo se requiere un índice entero, una duración en segundos o un valor opcional. Los ejemplos incluyen el resultado esperado y una acción para copiar la fórmula.

**Repeat** tiene una ficha para la fórmula de un período y **RepeatSamples** otra para la lista de valores. Las dos distinguen el uso continuo del discreto. Por ejemplo, en `Repeat(n+2,n,3,-1)`, el tramo base va de n = −1 a n = 1 y las muestras 1, 2 y 3 se repiten cada tres índices.

La referencia también explica cómo escribir trenes de pulsos e impulsos, escalones, sinc, funciones por tramos y constantes complejas. La Calculadora CAS enlaza una ficha de argumentos para comandos habituales como `diff`, `integrate`, `limit` y `solve`. [Guía de señales periódicas](../periodic-signals.md).
