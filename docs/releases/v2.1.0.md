# 2.1.0 Preview · Comunicaciones digitales

El laboratorio de comunicaciones digitales permite estudiar un enlace completo o ejecutar cada etapa por separado. Incluye modulación PSK y QAM cuadrada, pulsos rectangular, RC y RRC, AWGN y recepción con alineación conocida, asistida o estimada mediante un piloto. Los resultados incluyen constelación, señal I/Q, diagrama de ojo, espectro y mediciones BER, SER y EVM.

Workbench, Python y CLI comparten los mismos cálculos. Los experimentos conservan configuración, semillas, muestras y procedencia. Podés variar parámetros, comparar corridas, retomar un barrido interrumpido y exportar su tabla de métricas. [Ejemplos reproducibles](../engineering/phase_03/README.md)
