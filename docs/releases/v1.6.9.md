# SignalLab PC 1.6.9

Esta versión estable incorpora las mejoras de las preliminares 1.6.6, 1.6.7 y 1.6.8. Corrige el tratamiento de dominios en la hoja CAS y mejora el cálculo de la STFT con amplitudes extremas.

- El CAS conserva las exclusiones de una expresión al simplificar, guardar y sustituir. Las soluciones de una ecuación se contrastan con el dominio de partida. Los resultados obtenidos con supuestos conservan esas condiciones al reutilizarse.
- Las expresiones por tramos conservan el dominio de cada rama. Las desigualdades paramétricas que el CAS no puede resolver se muestran como conjuntos condicionales. Se admite la negación lógica.
- La conversión de trigonometría a exponenciales admite matrices. La sustitución recorre listas y diccionarios. La biblioteca distingue estas estructuras de las fórmulas escalares.
- Las respuestas de frecuencia trasladan sus exclusiones al análisis. Cuando un destino no puede aplicar una condición del CAS, la aplicación la señala antes de cargar el resultado.
- La STFT escala cada ventana antes de la FFT para evitar desbordamientos intermedios.

Disponible como portable para Windows x64 y Linux x86_64.
