# SignalLab PC 1.8.0 · Estable

SignalLab PC incorpora ediciones instalables para Windows x64 y Linux x86_64, con actualizaciones desde la propia aplicación. Los portables continúan disponibles y se conservan las herramientas y mejoras de estabilidad de la versión 1.7.0.

## Instalación y actualizaciones

Los instaladores incluyen Python y las dependencias necesarias. Se instalan para el usuario actual, sin permisos de administrador, y crean los accesos para iniciar y desinstalar la aplicación.

**Ayuda → Buscar actualizaciones** permite consultar el canal estable, descargar una versión nueva y elegir cuándo instalarla. La edición instalada también puede comprobar novedades al iniciar; esta opción se puede desactivar. La comprobación automática avisa, sin iniciar la descarga ni la instalación.

Las siguientes versiones se aplican sobre la misma instalación y conservan los temas y la configuración. Antes de reiniciar, la aplicación pide guardar o exportar los resultados de la sesión. En Linux, la versión nueva se prepara antes de activarla y se conserva una versión anterior para recuperarse si falla la activación.

## Integridad de las descargas

El actualizador verifica un manifiesto firmado con Ed25519, el tamaño del instalador y su SHA-256. Rechaza contenidos alterados, versiones anteriores y paquetes incompatibles con el equipo. La integridad se comprueba de nuevo antes de ejecutar el instalador.

Esta firma protege el canal de actualizaciones de SignalLab. **Los ejecutables Windows siguen sin firma Authenticode**: el Control inteligente de aplicaciones puede bloquear la primera instalación. El nuevo formato instalable no elimina esa limitación. [Alertas de Windows](https://github.com/Tincho1286/SignalLab-PC/blob/v1.8.0/docs/windows-downloads.md).
