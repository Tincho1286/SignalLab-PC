# SignalLab PC 1.8.0 · Estable

La versión 1.8.0 incorpora ediciones instalables y actualizables para Windows x64 y Linux x86_64. Los portables continúan disponibles y utilizan los mismos motores de cálculo; la entrega conserva las herramientas y mejoras de estabilidad de la 1.7.0.

## Instalación para el usuario

Los instaladores incluyen Python y las dependencias necesarias. En Windows, el archivo que termina en `-setup.exe` instala el programa por defecto en `%LOCALAPPDATA%\Programs\SignalLab PC` y registra los accesos y la desinstalación. En Linux, el `.run` se inicia con `sh ./SignalLab-PC-1.8.0-linux-x86_64.run`, instala en los datos del usuario y agrega el acceso al menú. Ambos trabajan sin permisos de administrador.

El portable Windows sigue siendo un ejecutable independiente y el portable Linux se distribuye como `.tar.gz`. Elegir ese formato permite continuar trabajando desde una carpeta sin registrar una instalación.

## Actualizar sin desinstalar

**Ayuda → Buscar actualizaciones** permite consultar el canal estable, descargar el instalador completo y elegir cuándo aplicarlo. La edición instalada también puede comprobar novedades al iniciar; esa consulta se puede desactivar y solo avisa, sin descargar ni instalar por sí sola.

La actualización conserva la carpeta, los accesos, los temas y la configuración. Antes de reiniciar, la aplicación pide guardar o exportar los resultados que se quieran conservar: la sesión completa no se recupera automáticamente. En Linux, los archivos nuevos se preparan antes de activarlos y se conserva una versión anterior para recuperarse si falla la activación.

## Integridad y límites de la firma

El actualizador verifica un manifiesto firmado con Ed25519, las direcciones oficiales, el tamaño y el SHA-256 de cada instalador. La integridad se comprueba de nuevo antes de ejecutarlo. Se rechazan contenidos alterados, manifiestos vencidos, paquetes incompatibles y retrocesos de versión, incluso si quedó abierta una ventana de una versión antigua.

La clave privada se utiliza localmente al preparar la entrega y permanece fuera de GitHub. Esta firma protege el canal de actualizaciones, pero **no es una firma Authenticode reconocida por Windows**. El Control inteligente de aplicaciones puede seguir bloqueando la primera instalación; convertir el programa en instalable no elimina esa limitación.
