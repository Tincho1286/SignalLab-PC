# Navegación 0.9.1

La aplicación inicia en un selector de tareas, sin pedir una señal global.
Cada categoría tiene un menú propio y cada cálculo una pantalla con entradas locales.
Los menús superiores permiten abrir directamente cualquier herramienta.
La búsqueda del inicio permite encontrar cálculos por nombre, con o sin acentos.
El proyecto conserva resultados para reutilizarlos; no es un paso previo obligatorio.

Esta entrega modifica la navegación. No certifica la paridad completa con HP Prime ni los módulos en desarrollo.
