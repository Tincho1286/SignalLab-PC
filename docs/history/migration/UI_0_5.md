# SignalLab PC 0.5 — herramientas independientes

Se reemplazó el inicio guiado y la señal global obligatoria por menús temáticos: Señales, Operaciones, Fourier, Filtros y sistemas, Control, Muestreo, Transformadas y Biblioteca.

Cada entrada del menú abre una instancia propia con parámetros, datos de entrada y resultados locales. Convolución, correlación y suma incluyen dos entradas. Los análisis de sistemas permiten ingresar coeficientes en su propia pantalla. La lectura JSON conserva dominios, ejes y metadatos para operaciones inversas. Las herramientas se conservan al navegar durante la sesión; el guardado es explícito.

La nueva ventana utiliza los motores existentes y mantiene el cálculo en segundo plano y su cancelación. El código anterior permanece como referencia y aporta utilidades compartidas, pero ya no es la ventana de inicio.

Se revisaron capturas de menús, convolución, Fourier continua y respuesta temporal a 1366 × 768. No se ejecutaron pruebas matemáticas ni una auditoría de integración del EXE en esta entrega. La paridad completa con HP Prime sigue pendiente.

Portable: outputs/SignalLab-PC-0.5-dev.exe. Versiones anteriores conservadas.
