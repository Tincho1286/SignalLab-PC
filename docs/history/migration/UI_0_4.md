# SignalLab PC 0.4 — recorrido guiado

Se simplificó la entrada a la aplicación: Inicio permite probar un coseno listo, crear una señal o abrir un JSON. El recorrido muestra Preparar señal, Ver mi señal y Elegir una acción. Desde el gráfico se puede continuar a acciones o guardar.

Las acciones tienen descripciones breves y se deshabilitan cuando necesitan una señal que aún no fue cargada. Las herramientas técnicas se despliegan desde Más herramientas. El ingreso por fórmula o muestras utiliza botones de selección visibles.

Se revisó la presentación de Inicio, Acciones y Crear mediante capturas Qt. No se ejecutaron pruebas matemáticas ni una auditoría funcional completa. La migración HP continúa en desarrollo. Las versiones anteriores se conservan.
