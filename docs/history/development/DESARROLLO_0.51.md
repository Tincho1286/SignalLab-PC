# SignalLab 0.51 · Rediseño de navegación y biblioteca

- Catálogo de acceso directo: nombres, descripciones, búsqueda por palabras y accesos temáticos. Se retiran el árbol lateral y el selector de tareas del entorno 0.50.
- Herramientas a ancho completo con sus datos conservados por separado. Contenedor desplazable para ventanas pequeñas, campos legibles y gráficos ampliables.
- Biblioteca sin pestaña Explorar ni controles de lección. Figuras estáticas con colores y leyendas, esquema específico de cada operación y explicaciones de parámetros. Se conservan las ilustraciones de bandas FIR/IIR. Las figuras compartidas por familia son ejemplos conceptuales, no resultados de entrada.
- Una sola fila de pestañas en las herramientas de diseño por especificaciones y análisis del curso; informe de cálculo separado de metadatos.
- Reutilización explícita de señales y sistemas conservada.

Validación acotada: apertura de catálogo, búsqueda, FIR y muestreo; revisión de capturas a 1366 × 768; generación de figuras de todas las páginas de herramientas. No se certifican todos los tamaños de pantalla ni toda la operativa numérica. Se conserva el motor de cálculo; esta entrega es una vista previa, no una versión estable 1.0.
