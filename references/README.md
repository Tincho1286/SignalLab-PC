# Referencias técnicas

Esta carpeta conserva la referencia de la implementación original para HP Prime y los inventarios utilizados al desarrollar las herramientas de PC. SignalLab PC es una aplicación independiente; no requiere una calculadora ni establece una conexión automática con su hardware.

- [Referencia de origen](REFERENCE.md): versión, archivo e identificación por hash.
- [Convenciones compartidas](SIGNALLAB_PC_VINCULO.md): criterios para comparar resultados y conservar información matemática.

Las guías de uso vigentes están en [docs/](../docs/README.md).
